## ③ 想強調哪些功能（管理者視角）

對「老闆 / 工廠管理者」最有感的順序：

1. **一眼看到問題** — 首頁三大區（綜合狀態 / 設備清單 / 即時告警）一目了然
2. **即時告警** — 右上鈴鐺彈出最近告警；底部跑馬燈滾動異常項目（不用守著看）
3. **趨勢回放** — 一頁看遍所有感測點，越界自動標紅
4. **上下限線上設定** — 不用改 code、不用重啟，UCL/LCL 即改即生效
5. **多產線輪播** — 一鍵掛上產線大螢幕，自動切換看板

## ⑤ 操作提示

關鍵 aria-label / 選擇器（5/19 之後新增 / 變動的）：

- 告警鈴鐺：頂部右側 button（icon-only）— 需要點開後 dropdown 浮出
- 底部跑馬燈：footer 區的滾動文字條（純展示，不互動）
- 分頁切換：`button` with text `總覽` / `趨勢` / `輪播` / etc.
- 限值設定：`[aria-label="限值設定（UCL/LCL）"]`
- 播放：`[aria-label="Start auto-play"]` / 停止：`[aria-label="Stop auto-play"]`
